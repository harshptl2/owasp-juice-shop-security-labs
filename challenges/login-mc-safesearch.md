# Login MC SafeSearch – OWASP Juice Shop

## Category
Sensitive Data Exposure / Information Disclosure

## What I Learned

This challenge helped me understand how sensitive information exposed through an application can potentially affect account security.

I learned that credentials and other sensitive information should never be exposed through publicly accessible content.

## Security Concept

Information Disclosure occurs when an application unintentionally reveals sensitive information that should not be available to unauthorized users.

## What I Practiced

- Analyzing publicly accessible application content
- Looking for sensitive information exposure
- Understanding how information disclosure can affect authentication security
- Identifying security risks caused by exposed information

## Key Takeaway

Sensitive information such as passwords, credentials, tokens, and internal details should never be exposed to unauthorized users.

## Environment

OWASP Juice Shop running in a controlled local lab environment.
