# Product Tampering – OWASP Juice Shop

## Category
Broken Access Control / Authorization

## What I Learned

This challenge helped me understand the importance of protecting application data from unauthorized modification.

I learned that applications should verify whether a user is authorized to modify a particular resource.

## Security Concept

Broken Access Control can allow users to perform actions or modify data that they should not be permitted to change.

## What I Practiced

- Analyzing product-related functionality
- Understanding authorization controls
- Testing whether application data is properly protected
- Understanding server-side access control

## Key Takeaway

Applications should enforce proper authorization checks before allowing users to modify protected resources.

## Environment

OWASP Juice Shop running in a controlled local lab environment.

This documentation is for educational purposes. All testing was performed in an authorized local lab environment.
