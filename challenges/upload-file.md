# Upload File – OWASP Juice Shop

## Category
File Upload Security / Input Validation

## What I Learned

This challenge helped me understand the security risks associated with file upload functionality.

I learned that applications should properly validate uploaded files instead of trusting only the file name or extension.

## Security Concept

Improperly secured file uploads can allow users to upload files that should not be accepted by the application.

## What I Practiced

- Analyzing file upload functionality
- Understanding file type validation
- Understanding extension and content validation
- Identifying security risks related to unrestricted file uploads

## Key Takeaway

File uploads should be securely validated on the server side, and applications should restrict allowed file types and safely handle uploaded content.

## Environment

OWASP Juice Shop running in a controlled local lab environment.
