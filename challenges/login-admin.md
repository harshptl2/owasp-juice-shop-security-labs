# Login Admin – OWASP Juice Shop

## Category

## What I Learned

This challenge helped me understand how authentication weaknesses can lead to unauthorized access to privileged functionality.

I learned that administrative accounts require strong authentication and proper authorization controls.

## Security Concept

The main concept covered in this challenge is authentication security and protection of privileged accounts.

## What I Practiced

- Analyzing login functionality
- Understanding authentication behavior
- Identifying weaknesses in access to privileged functionality
- Understanding the importance of strong authentication

## Key Takeaway

Authentication and authorization should always be properly implemented and enforced on the server side.
