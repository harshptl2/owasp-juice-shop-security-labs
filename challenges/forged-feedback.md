# Forged Feedback – OWASP Juice Shop

## Category
Broken Access Control / Authorization

## What I Learned

This challenge helped me understand how authorization controls should protect application functionality.

I learned that an application should verify whether a user is allowed to perform an action before accepting the request.

## Security Concept

Broken Access Control can occur when an application trusts client-side requests without properly validating permissions on the server side.

## What I Practiced

- Analyzing application requests
- Understanding authorization checks
- Testing whether functionality is properly restricted
- Understanding the importance of server-side validation

## Key Takeaway

Security-sensitive actions should always be validated on the server side and should not rely only on client-side controls.

## Environment

OWASP Juice Shop running in a controlled local lab environment.
