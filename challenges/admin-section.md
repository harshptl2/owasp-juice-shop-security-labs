# Admin Section – OWASP Juice Shop

## Category
Broken Access Control

## What I Learned

This challenge helped me understand Broken Access Control and why administrative functionality must be properly protected.

I learned that an application should verify whether a user is authorized to access privileged functionality.

## Security Concept

Broken Access Control occurs when an application does not properly enforce restrictions on what authenticated or unauthenticated users are allowed to access.

## What I Practiced

- Testing access to administrative functionality
- Understanding authorization controls
- Identifying whether privileged functionality is properly restricted
- Understanding the difference between authentication and authorization

## Key Takeaway

Authentication verifies who the user is, while authorization determines what the user is allowed to access.

## Environment

OWASP Juice Shop running in a controlled local lab environment.
