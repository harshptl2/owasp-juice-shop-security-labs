# View Basket – OWASP Juice Shop

## Category
Broken Access Control / Authorization

## What I Learned

This challenge helped me understand how access control should protect user-specific resources.

I learned that an application should verify whether the current user is authorized to access a particular basket or resource.

## Security Concept

Broken Access Control can occur when an application fails to properly verify ownership or authorization before providing access to a resource.

## What I Practiced

- Testing access control for user-specific resources
- Understanding authorization checks
- Analyzing how the application handles user resources
- Identifying potential unauthorized access

## Key Takeaway

Applications should perform proper server-side authorization checks for every protected resource.

## Environment

OWASP Juice Shop running in a controlled local lab environment.
