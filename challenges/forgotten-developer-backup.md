# Forgotten Developer Backup – OWASP Juice Shop

## Category
Sensitive Data Exposure / Information Disclosure

## What I Learned

This challenge helped me understand the security risks of exposed backup files and sensitive application information.

I learned that backup files should not be publicly accessible because they may contain sensitive information or internal application details.

## Security Concept

Information Disclosure can occur when backup files or other sensitive resources are unintentionally exposed to unauthorized users.

## What I Practiced

- Analyzing publicly accessible application resources
- Understanding risks related to exposed backup files
- Identifying potential information disclosure
- Understanding the importance of secure file and backup management

## Key Takeaway

Backup files and sensitive resources should be properly protected and should not be publicly accessible.

OWASP Juice Shop running in a controlled local lab environment.
