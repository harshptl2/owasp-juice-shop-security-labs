# Poison Null Byte – OWASP Juice Shop

## Category
Input Validation / File Handling

## What I Learned

This challenge helped me understand how special characters can affect the way an application processes file names and paths.

I learned that applications need to properly validate and sanitize user-controlled input before using it in file or path operations.

## Security Concept

Improper input validation can cause unexpected application behavior when specially crafted input is processed.

## What I Practiced

- Analyzing file and path handling
- Understanding input validation
- Observing how special characters affect application behavior
- Understanding the importance of secure input handling

## Key Takeaway

User-controlled input should always be properly validated and handled before being used in file or path operations.
