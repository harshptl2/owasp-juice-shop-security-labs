# Reset Jim's Password – OWASP Juice Shop

## Category
Authentication / Password Reset

## What I Learned

This challenge helped me understand the security risks associated with password reset functionality.

I learned that password recovery mechanisms must properly verify the identity of the user before allowing a password to be changed.

## Security Concept

Weak password reset mechanisms can allow unauthorized users to reset another user's password.

## What I Practiced

- Analyzing password reset functionality
- Understanding authentication workflows
- Testing security controls around account recovery
- Understanding the importance of proper identity verification

## Key Takeaway

Password reset functionality should use strong identity verification and secure recovery mechanisms to prevent unauthorized account access.

OWASP Juice Shop running in a controlled local lab environment.
