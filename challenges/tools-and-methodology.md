# Tools & Security Testing Methodology

## Tools Used

- OWASP Juice Shop
- Burp Suite
- Browser Developer Tools
- Docker

## Testing Methodology

The testing was performed in a controlled local lab environment using OWASP Juice Shop.

The general approach included:

1. Understanding the application's functionality.
2. Observing application behavior through the browser.
3. Identifying potential security weaknesses.
4. Analyzing authentication and authorization controls.
5. Testing input validation and file handling.
6. Reviewing how sensitive information is handled.
7. Understanding business logic and security controls.
8. Documenting the security concepts learned from each challenge.

## Security Areas Practiced

- Authentication
- Authorization
- Broken Access Control
- Input Validation
- Information Disclosure
- Sensitive Data Exposure
- File Upload Security
- Business Logic Security
- Anti-Automation Controls
- Error Handling

## Environment

All testing was performed locally in an intentionally vulnerable application designed for cybersecurity education.

## Disclaimer

This project is for educational purposes only. Testing was performed only in an authorized and controlled lab environment.
