# CAPTCHA Bypass – OWASP Juice Shop

## Category
Security Control / Anti-Automation

## What I Learned

This challenge helped me understand the purpose of CAPTCHA as a protection against automated requests and repeated actions.

I learned that security controls such as CAPTCHA must be properly implemented and enforced.

## Security Concept

If an anti-automation control is implemented incorrectly, it may be possible to bypass or weaken the protection.

## What I Practiced

- Analyzing CAPTCHA behavior
- Understanding anti-automation controls
- Observing how security controls are enforced
- Understanding the importance of server-side validation

## Key Takeaway

Security controls should be enforced properly on the server side and should not rely only on client-side checks.

## Environment

OWASP Juice Shop running in a controlled local lab environment.
